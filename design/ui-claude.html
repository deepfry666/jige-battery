托盘图标

16 / 24 / 32 px 分别对应 100% / 150% / 200% 缩放。按显示器 DPI 现画，数字只用两位，字重随尺寸加粗。

规范

托盘图标、面板和提醒共用一套颜色和动效。

动效

  • 展开：上移 16px 并淡入，250ms，曲线 (0.1, 0.9, 0.2, 1)，和 Windows 11 自带面板一致
  • 收起：120ms 加速淡出，不拖泥带水
  • 设备行依次进场，每行晚 25ms
  • 充电：下一格呼吸闪烁，1.6s 一个周期
  • 系统开启"减少动画"时全部关闭

状态颜色

正常 · 强调色 ≤ 30% ≤ 15% · 提醒 充电中 休眠 / 离线 / 被占用
  • 颜色只表示状态，正常时跟随系统强调色
  • 电压估算的读数前加 ≈，不冒充精确值

文字层级

  • 主设备数字 46px，Segoe UI Variable Display，等宽数字
  • 列表数字 20px，名称 13.5px，状态 12px
  • 状态说明只在异常时出现；正常时只写"2.4G 已连接"

打扰规则

  • 游戏全屏时不弹窗，提醒排队到退出后
  • 同一设备每次低电量只提醒一次，"稍后提醒"延 1 小时
  • 面板失去焦点即收起，Esc 也可收起
