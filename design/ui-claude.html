托盘图标（0.2.6）

两种托盘模式都用设备图形和底部电量条，悬停可看百分比。依次展示 16、24、32px 和放大 3 倍的 16px 图标。

悬停卡片（0.2.5）

收起上方主面板后，把鼠标移到任务栏图标上可实时预览；下方同步展示自定义单设备与最低电量列表两种模式（固定宽 248px，不显示已断开设备）。

规范

托盘图标、面板和提醒共用一套颜色和动效。

动效

  • 主面板展开：上移 16px 并淡入，250ms，曲线 (0.1, 0.9, 0.2, 1)，和 Windows 11 自带面板一致
  • 主面板收起：120ms 加速淡出，不拖泥带水
  • 悬停卡片：约 130–140ms 淡入淡出，点击穿透且不抢焦点
  • 设备行依次进场，每行晚 25ms；充电下一格呼吸闪烁，1.6s 一周期
  • 系统开启"减少动画"时全部关闭

状态颜色

正常 · 强调色 ≤ 30% ≤ 15% · 提醒 充电中 休眠 / 离线 / 被占用
  • 颜色只表示状态，正常时跟随系统强调色
  • 电压估算的读数前加 ≈，不冒充精确值

文字层级

  • 主设备数字 46px，Segoe UI Variable Display，等宽数字
  • 列表数字 20px，名称 13.5px，状态 12px
  • 状态说明只在异常时出现；正常时只写"2.4G 已连接"

打扰规则

  • 游戏全屏时不弹窗，提醒排队到退出后
  • 同一设备每次低电量只提醒一次，"稍后提醒"延 1 小时
  • 面板失去焦点即收起，Esc 也可收起
