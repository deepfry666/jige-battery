# 用 Wireshark + USBPcap 抓取官方软件读电量教程

当你的 2.4 GHz 无线外设在 `diagnostics.txt` 里能看到接收器，但公开开源资料里还没有它的电量查询协议时，抓一次**官方软件打开并显示电量**的 USB 通信包，就能帮几格以严格只读的方式适配这台设备。

整个过程大约 5 分钟，不需要写代码。

---

## 第一步：安装 Wireshark（务必勾选 USBPcap）

1. 前往 [Wireshark 官网](https://www.wireshark.org/download.html) 下载 Windows x64 安装包并运行。
2. 安装过程中会看到组件选择页，请按默认安装 Wireshark；接着在 **Install USBPcap** 页面，**务必勾选安装 USBPcap**（没有它就抓不到 USB 数据）。
3. 如果安装完成后提示需要重启电脑，请先重启，否则 USBPcap 驱动不会生效。

## 第二步：抓包前的准备

1. **彻底关闭官方驱动软件**：
   - 先打开官方软件看一眼设备当前电量和充电状态并记下来（比如「当前 68%，未充电」）。
   - 然后彻底退出官方软件，并检查任务栏右下角托盘图标区（点 `^` 展开），确保官方软件的后台图标也已退出；也可以在任务管理器里确认没有官方界面进程残留。
   - 如果同时开着几格，也先右键任务栏直读条或托盘图标选「退出」，避免抓包里混入几格的查询。
2. **确认无线设备已开机并连上接收器**：
   - 鼠标轻轻晃动一下确认处于唤醒状态；耳机或键盘确认已开机并连上 2.4 GHz 接收器。
3. **尽量减少无关输入**：
   - 抓包期间请不要在键盘上输入密码、聊天内容或敏感信息（因为同一条 USB 总线上的设备流量可能被一并录下；第六步会教你只导出目标接收器的数据）。

## 第三步：找到接收器所在的 USBPcap 接口

1. 以**管理员身份**打开 Wireshark（USBPcap 读取 USB 根集线器通常需要管理员权限）。
2. 在首页接口列表里，你会看到若干个 `USBPcap1`、`USBPcap2`、`USBPcap3`……
3. 判断目标接收器在哪个 `USBPcap` 接口：
   - **方法 1（推荐，点接口旁的齿轮图标）**：点击 `USBPcap1` 左侧的小齿轮，可以看到它下面挂着哪些 USB 设备；逐个点开看哪一个下面有你的鼠标/耳机接收器，记下这个 `USBPcapX`。
   - **方法 2（插拔确认）**：如果不确定，先按住 `Ctrl` 选中全部 `USBPcap*` 接口开始抓包，再把目标接收器拔出重新插一次，看到新出现的 USB 设备对应的端口即可。

## 第四步：开始抓包并打开官方软件

1. 双击目标接收器所在的 `USBPcapX` 接口，Wireshark 开始实时滚动抓包（左上角蓝色鲨鱼鳍变灰、红色方形停止按钮亮起）。
2. 等待 2 秒后，**打开官方驱动软件**（如果是网页驱动，例如 ATK HUB 网页版或 mouse.xyz，就打开浏览器连接该设备）。
3. **等待官方界面显示出准确的电量百分比**（通常需要 3～10 秒）。
4. （可选，非常有帮助）如果方便，此时可以**把 USB 充电线插到设备上停 3 秒、看到官方软件显示「充电中」，再拔掉停 3 秒**，这样一份抓包就能同时拿到电量和充电状态的报文。
5. 记下此时官方界面显示的精确百分比（例如 `68%`，插线后变为 `充电中`）。

## 第五步：停止并保存 `.pcapng`

1. 回到 Wireshark，点击左上角**红色方形停止按钮**（Stop）。
2. 如果你不想把同一 USB 集线器上其他设备（比如键盘、U 盘）的数据一起分享，**强烈建议先按第六步过滤后再保存**。
3. 直接保存全部抓包：菜单栏点击 **File → Save As…**（文件 → 另存为），格式保持默认的 **Wireshark/… - pcapng**，保存为例如 `my-mouse-battery.pcapng`。

## 第六步：只导出目标接收器的数据（强烈推荐，保护隐私）

同一条 `USBPcap` 总线上可能同时挂着你的键盘和鼠标。导出前过滤出目标接收器，就能把键盘按键等无关数据彻底剔除：

1. 先查看 `diagnostics.txt` 里目标接收器的 `VID` 和 `PID`（例如 `373B` 和 `11D9`）。
2. 在 Wireshark 顶部的显示过滤器（Display Filter）输入框里输入：
   ```text
   usb.idVendor == 0x373b && usb.idProduct == 0x11d9
   ```
   （把 `373b` 和 `11d9` 换成你自己的接收器 VID/PID，按回车。）
   > 如果抓包期间没有插拔接收器，可能看不到设备描述符包；此时可以翻看带 `HID` / `URB_INTERRUPT` / `GET_REPORT` / `SET_REPORT` 的行，选中一条你移动鼠标或打开驱动时出现的数据包，在下方详情栏展开 `USB URB`，记下它的 `Bus Id` 和 `Device Address`（例如 `2` 和 `5`）。
3. 在显示过滤器输入（把 `2` 和 `5` 换成你的总线号和设备地址）：
   ```text
   usb.bus_id == 2 && usb.device_address == 5
   ```
   按回车，确认列表里只剩下这一台接收器的通信包。
4. 点击菜单栏 **File → Export Specified Packets…**（文件 → 导出特定分组…）：
   - 在下方范围选择 **Displayed**（仅已显示的分组）；
   - 文件类型选择 **pcapng**，保存为新文件（例如 `my-mouse-filtered.pcapng`）。

## 第七步：提交给几格

在 GitHub 使用 [设备电量报告](https://github.com/deepfry666/jige-battery/issues/new?template=device-report.yml) 提交 issue，附上：

1. 设备完整型号与接收器类型；
2. 抓包时官方软件显示的**精确电量百分比**和**充电状态**（如果测试了插拔充电线，也请写明）；
3. 完整的 `diagnostics.txt`；
4. 第五或第六步保存的 `.pcapng` 文件（如果 GitHub 提示不支持 `.pcapng` 附件后缀，将其压缩为 `.zip` 后直接拖入文本框即可）。
