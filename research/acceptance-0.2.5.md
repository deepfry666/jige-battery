# 0.2.5 验收标准：托盘图标区分设备、自定义悬停卡片

用户 2026-11-20 定下两项改动：

- 托盘多个图标同时显示时，要能分清哪个图标是哪台设备。采用方案 A：图标上方是小设备图形，下方是数字。
- 悬停提示改成好看的自定义卡片，替换 Windows 默认的文字提示。

## T. 托盘图标（方案 A）

- T1：托盘图标分两部分：上方是小的设备类型图形，下方是电量数字。
  - 设备类型分鼠标、键盘、耳机、其他四种。
  - 数字仍然是主体：16px 时数字高 10px，24px 时 15px，32px 时按比例放大。
  - 现有的颜色规则不变（低电量、偏低、充电、休眠）。
- T2：重画鼠标、键盘、耳机、其他四种图形，要求 16px（100% 缩放）下肉眼能分辨，24px、32px 分别有对应的像素版或矢量版。深色、浅色任务栏都清楚可读。
- T3：电量 100% 时，在宽度有限的情况下照样放得下（例如用「满」或缩小的「100」），沿用现有规则，不能截断。
- T4：「只显示电量最低的一台」模式下，单个图标同样带设备类型图形；没有活跃设备时，「几格」图标保持现状。
- T5：单元测试覆盖每种设备类型和每种尺寸下的布局计算，图形不能和数字重叠或越界。

## H. 自定义悬停卡片

- H1：托盘图标改用 `NOTIFYICON_VERSION_4`，不设置 `NIF_SHOWTIP`，并处理 `NIN_POPUPOPEN` 和 `NIN_POPUPCLOSE`：前者显示几格自己画的悬停卡片，后者隐藏。Windows 默认的文字提示不再出现。`szTip` 仍然填写，供读屏软件使用。
- H2：卡片窗口要满足：
  - 不抢焦点：`WS_EX_NOACTIVATE`、`WS_EX_TOOLWINDOW`、`WS_EX_TOPMOST`，不在任务栏和 Alt+Tab 里出现；
  - 鼠标点击穿透，或者点击后直接打开主面板；
  - 主面板打开时不显示卡片。
- H3：卡片位置在被悬停的图标上方，水平方向对准图标中心，贴着任务栏，留出系统标准间距。任务栏在顶部、左侧、右侧时相应调整。多显示器、不同 DPI 下位置和尺寸都正确。
- H4：视觉按设计稿：
  - Windows 11 风格，圆角 8px，带阴影；
  - 底色用 Acrylic 或 Mica；系统关闭透明效果时改用纯色；
  - 跟随系统深浅色；
  - 出现和消失有约 120–150ms 的淡入淡出，系统关闭动画时不播放动画；
  - 字体用 Segoe UI Variable，Windows 10 回退到 Segoe UI。
- H5：内容分两种：
  - 「自定义」模式（每台设备一个图标）：卡片显示这台设备。依次是设备图形；名称；连接方式标签（2.4G / 蓝牙 / USB）和来源（例如「罗技 Bolt 接收器」）；大号百分比，`≈` 表示估算；10 格电量条；状态行（电量偏低、充电中、已充满、休眠中，以及「N 分钟前读取」）。
  - 「只显示电量最低的一台」模式：卡片列出所有在用设备（在线或休眠中），每行是图形、名称、状态、5 格小电量条和百分比，按电量从低到高排列，最多 6 行，超出的显示「还有 N 台」。
  - 两种模式都不显示已断开的设备。
- H6：卡片显示期间读数更新时，内容跟着刷新。卡片宽度固定在约 248px（随 DPI 缩放），名字过长时省略显示。
- H7：设计原型 `design/ui-claude.html` 加入托盘图标的新样式和悬停卡片两种模式，可以交互预览。
- H8：单元测试覆盖：卡片内容的生成（两种模式、各种状态、过长名字、超过 6 台设备）；位置计算（任务栏在四个方向、多显示器边界）；游戏中不显示；主面板打开时不显示。
