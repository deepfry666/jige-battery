# 几格问题与待办总表

更新：2026-11-19（当前版本 v0.2.1）。问题来源包括用户实机反馈、CI，以及[三方评审](review-summary.md)。

## 一、已修复

| 版本 | 问题 | 怎么发现的 | 怎么修的 |
|---|---|---|---|
| 发布前 | 托盘程序一启动就退出 | CI 自检 | 入口加上 `[STAThread]`，COM 初始化不再冲突 |
| 发布前 | 托盘只识别 ULX 的接收器，ATK、游狼不会被检测 | 合并代码时审查 | 托盘、探针、诊断统一使用同一套接收器识别规则 |
| 发布前 | 罗技一个接收器下的多台设备只读到一台 | 合并代码时审查 | 托盘和诊断改为多设备读取 |
| 0.1.1 | 游狼 HTX Ultra 8K 只登记、不读取 | 第一份实机诊断 | 依据官方网页驱动的型号表启用，实机读到 38% |
| 0.1.1 | 诊断报告只列已知品牌，ULX 和 ATK 完全看不到 | 第一份实机诊断 | 列出所有品牌的厂商自定义接口 |
| 0.1.2 | 点开面板就闪退 | 用户反馈 | 用户主动点击不再受"游戏中"判定拦截；桌面、任务栏不再被误判为全屏游戏 |
| 0.1.3 | 主设备以外的设备行和刷新按钮发灰 | 用户截图 | DirectComposition 图层叠放顺序写反了，已改正 |
| 0.2.0 | 齿轮和「管理设备」点了会"跳"到右键菜单 | 用户反馈 | 改为在面板内切换到设置页、设备页 |
| 0.2.0 | 设置页 UI 很奇怪 | 用户反馈 | 改为一张分组卡片，选项在行内展开 |
| 0.2.1 | 游戏中不打扰基本不起作用：窗口化游戏漏判，诊断导出后弹记事本，右键菜单退出游戏后乱弹 | 评审 #7 | 支持识别无边框窗口和游戏进程名，游戏中不弹任何东西 |
| 0.2.1 | 低电量提醒不准：充电中也提醒、用过期读数提醒、被挡住后就不再提醒、颜色和阈值不一致 | 评审 #3 | 规则重写，颜色跟随阈值 |
| 0.2.1 | 罗技、雷蛇的诊断报告标错品牌、回复被清零 | 评审 #8 | 按真实适配器标注，只遮蔽标识字段，报告可以回放 |
| 0.2.1 | 日志会带上系统报错原文和其他软件的窗口名 | 评审 #9 | 只记录错误码和窗口类别 |
| 0.2.1 | 首次使用没有引导，开机自启默认关闭，托盘图标注册失败不重试 | 评审 #6 | 加首次引导卡片，安装时默认勾选开机自启，注册失败自动重试 |
| 0.2.1 | 卸载不经确认就清空设置；配置损坏后被直接覆盖 | 评审 #15 | 卸载时询问；损坏的配置先备份再恢复默认 |
| 0.2.1 | 离线设备删不掉，改名后无法还原 | 评审 #12 | 可以移除离线设备，清空名称即恢复默认 |
| 0.2.1 | 诊断导出没有反馈，连点会重复导出；未识别的接收器没有任何提示；悬停提示放不下就整行消失；提醒卡片图标不统一；文档过时 | 评审 #16 #1 #20 #17 #18 | 逐项修复 |

## 二、待办（未开工）

### A. 设备识别

| 问题 | 方案 | 状态 |
|---|---|---|
| **ATK F1 Ultimate 2.0（用户写作"F1 Limited 2.0"，待确认）识别不到**。清单里有这一款，但接收器 PID 未核实，所以默认没有启用 | 改为按协议家族通用识别，参考 HaloBattery 的做法：只看厂商和接口特征（Compx 是 `FF02`、17 字节），不再要求具体型号 | 用户已同意方向，记入待办 |
| **Finalmouse ULX 识别不到**。目前只认 `361D:0100` 一个 PID，诊断里也没有看到 `361D` 接口 | 同上，凡是 `361D` 厂商、带 ULX 家族接口的接收器都尝试读取；仍需一份 0.2.x 诊断确认接收器在系统里可见 | 同上 |
| 通用识别的三道安全门 | ① 厂商和接口特征必须唯一对应一个家族；② 第一条只发状态查询，回复格式对了才继续；③ 回复不对就永久停止，并记住这个接收器 | 设计已定 |
| 游狼新旧两代协议的接口特征一样，无法按接口区分 | 导入官方网页驱动的完整型号表 | 设计已定 |

### B. 在线状态、托盘与面板（用户已定，见 [issues-device-presence.md](issues-device-presence.md)）

| 问题 | 已定方案 |
|---|---|
| 设备关机后最长要 60 秒才显示断开 | 每 5～10 秒做一次轻量在线检查，游戏中放慢到 30 秒；罗技改为监听接收器推送；H9 单独处理；拔掉接收器靠系统通知立即生效 |
| 「固定在托盘」只能选一台 | 取消"固定"。托盘提供两种模式：每台设备一个图标（默认，在设备页勾选），或只用一个图标显示电量最低的设备 |
| 固定的旧设备一直占着面板顶部，新鼠标排不上去 | 顶部大卡片自动显示电量最低的在线设备，离线设备折叠到底部 |
| 设备关机后托盘图标怎么显示 | 保留图标，变灰并显示上次读数 |
